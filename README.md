# 🚀 Israel Dawit Samuel | Full-Stack Portfolio

This is my personal portfolio website built as part of the **Future Interns Full Stack Web Development Internship (Task 1)**.

It showcases my skills, projects, and professional profile using modern web technologies and a clean, scalable architecture.

---

## ✨ Key Features

- Modern UI with smooth animations (Framer Motion)
- Fully responsive mobile-first design
- Component-based architecture using React + TypeScript
- Dark/Light mode support
- Clean and scalable project structure

---

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Build Tool**: Vite
